# FileFlow – Intelligent File Organizer

## 📌 Project Overview

FileFlow is a Python-based application designed to organize files into different categories and analyze folder contents. It helps users manage files efficiently and understand their file distribution through data analysis and visualizations.

## ✨ Features

* **File Organization:** Organizes files based on their file extensions.
* **Folder Analysis:** Counts files and categorizes them into different groups.
* **Data Analytics:** Uses Pandas to analyze file data.
* **Numerical Analysis:** Uses NumPy to calculate totals, averages, maximums, and minimums.
* **Data Visualization:** Displays file analysis using charts.
* **Interactive GUI:** Provides a graphical user interface built with Tkinter.
* **Functional Programming:** Uses `map()`, `filter()`, `reduce()`, and lambda functions.
* **Object-Oriented Programming:** Uses classes, objects, inheritance, and encapsulation.

## ⚙️ Installation and Setup

### 1. Install Python

Install Python 3.14 and make sure Python is available through the Windows Python Launcher.

### 2. Open the Project Folder

Open the FileFlow project folder in Visual Studio Code.

### 3. Install Required Libraries

Open the VS Code terminal and run:

```powershell
py -3.14 -m pip install pandas numpy matplotlib seaborn plotly
```

### 4. Run the Application

Run the following command in the terminal:

```powershell
py -3.14 gui.py
```

## 🚀 How to Use

1. Launch the FileFlow application.
2. Select the folder you want to analyze or organize.
3. Use the organization feature to arrange files into categories.
4. Use the analysis feature to view file counts and category statistics.
5. Explore the available visualizations to understand the distribution of files.

**Note:** Test file organization on a sample folder first. Keep a backup of important files before organizing them.
